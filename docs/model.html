SE-TCN Network Architecture Specifications

The network processes 4-second sliding windows of 8 inertial channels (tri-axial accelerometer, tri-axial gyroscope, forward acceleration magnitude, and jerk rate).

Input Shape [1, 8, 40] 4.0s window @ 10 Hz
Causal Dilations d ∈ {1, 2, 4, 8} Zero future-frame leakage
Attention Block Squeeze-and-Excitation Channel-wise reweighting
Inference Rate 20 Hz (50ms loop) <8% mobile CPU load
