System Deep-Dive

6-Stage Algorithmic Architecture

Click any stage below to inspect mathematical formulations and production C++ / Dart code:

Stage 01 • Kinematic Alignment

Mahony SO(3) & PCA Azimuth Lock ⚙

Estimates pitch and roll from gravity vector; extracts vehicle forward azimuth via Principal Component Analysis of horizontal acceleration.

$$\hat{\mathbf{g}} = \frac{\bar{\mathbf{a}}}{\|\bar{\mathbf{a}}\|}, \quad \mathbf{C} = \frac{1}{N}\sum \mathbf{a}_{\text{hor}}\mathbf{a}_{\text{hor}}^T$$
// C++20 SIMD Mahony Leveling Implementation Eigen::Vector3d a_bar = imu_buffer.rowwise().mean(); Eigen::Vector3d g_hat = a_bar.normalized() * 9.80665; Eigen::Matrix2d C = horiz_accel.transpose() * horiz_accel / N; Eigen::SelfAdjointEigenSolver es(C); double vehicle_heading = std::atan2(es.eigenvectors()(1,1), es.eigenvectors()(0,1));
Stage 02 • Vibration & Shock Gating

Jerk Shock Gate & Skog GLRT ZUPT 🛡

Computes discrete jerk variance over a 250ms sliding window to reject pothole shocks; clamps velocity to zero during traffic idling.

$$\sigma_j^2 = \text{Var}\left(\frac{\Delta a}{\Delta t}\right) > 450\text{ m/s}^6 \implies \mathbf{Q} \leftarrow 50\mathbf{Q}$$
// Vibration Shock Rule & Standstill ZUPT if (jerk_variance > 450.0) { ekf.inflate_process_noise(50.0); // Shock protection } if (skog_glrt_statistic(imu_window) < ZUPT_GAMMA) { ekf.apply_zero_velocity_update(); // Red-light lock }
Stage 03 • Deep Neural Kinematics

8-Channel Dilated Causal SE-TCN 🧠

4.0-second temporal receptive field predicting forward speed $\hat{v}$ and heteroscedastic log-variance $s = \log(\sigma_v^2)$ via Gaussian NLL loss.

$$\mathcal{L}_{\text{NLL}} = \frac{1}{2}\exp(-s)\|v - \hat{v}\|^2 + \frac{1}{2}s$$
// 2.1 MB INT8 ONNX Runtime Inference Ort::Value input_tensor = Ort::Value::CreateTensor(...); auto outputs = session.Run(run_options, input_names, &input_tensor, 1, output_names, 2); float v_hat = outputs[0].GetTensorMutableData()[0]; float sigma_v = std::sqrt(std::exp(outputs[1].GetTensorMutableData()[0]));
Stage 04 • Multi-Sensor Fusion

15-State 3D Error-State EKF (ES-EKF) 🧭

Propagates position, velocity, and attitude error with gyro/accel bias tracking. Enforces Non-Holonomic Constraints ($v_{\text{lat}} \approx 0$).

$$\delta\mathbf{x} = [\delta\mathbf{p}, \delta\mathbf{v}, \delta\boldsymbol{\theta}, \mathbf{b}_a, \mathbf{b}_g]^T \in \mathbb{R}^{15}$$
// Joseph-Form Covariance Stabilization Eigen::Matrix I_KH = I15 - K * H; P = I_KH * P * I_KH.transpose() + K * R * K.transpose(); nominal_state.p += delta_x.segment<3>(0); nominal_state.v += delta_x.segment<3>(3);
Stage 05 • Geometric Map Matching

Orthogonal OSM Snapping & Barometer 🗺

Projects raw filter coordinates onto offline OpenStreetMap GeoJSON road segments with barometric multi-level flyover deck resolution.

$$\mathbf{p}_{\text{snap}} = \mathbf{p}_0 + ((\mathbf{p}_{\text{raw}} - \mathbf{p}_0)\cdot\hat{\mathbf{u}})\hat{\mathbf{u}}$$
// Offline Vector Map Matching (15 MB/City GeoJSON) RoadSegment seg = spatial_rtree.find_nearest_bearing(p_raw, heading); double proj = (p_raw - seg.p0).dot(seg.u_unit); Vector2d snapped = seg.p0 + std::clamp(proj, 0.0, seg.length) * seg.u_unit; double delta_h = 44330.0 * (1.0 - std::pow(P / P0, 0.1903));
Stage 06 • Outage Transition

Continuous Sigmoidal HDOP Gate ⚡

Continuously inflates GNSS measurement covariance during tunnel entry, eliminating map icon jumps and providing smooth handoff.

$$\lambda(h) = \frac{1}{1 + e^{-1.2(h - 3.5)}}, \quad \mathbf{R}_{\text{eff}} = (1 + 99\lambda)\mathbf{R}_{\text{GNSS}}$$
