Network Architecture & Pipeline

How the 8-channel temporal network translates inertial vibration patterns into speed.

Input Window

4.0s Sliding Window (40 Steps @ 10Hz)

Takes 8 physical channels: tri-axial accelerometer, tri-axial gyroscope, vertical jerk magnitude, and chassis pitch angle. Downsampled to 10 Hz to balance power consumption and capture wheel-rolling harmonics.

Convolutions

Dilated Causal Residual Blocks

5 dilated convolution layers with expansion factors $d \in \{1, 2, 4, 8, 16\}$. Causal padding prevents future information leakage, while Squeeze-and-Excitation attention gates focus on the most informative sensor channels.

Dual Head Output

Speed ($\hat{v}_x$) & Uncertainty ($\sigma^2$)

Trained with Gaussian Negative Log-Likelihood (NLL). When encountering unmodeled dynamics (e.g. sudden wheel slip or severe potholes), the network automatically outputs high variance $\sigma^2$, prompting the Kalman filter to lower measurement trust.

Python Inference Quickstart

Run inference on the downloaded ONNX model with standard onnxruntime.

import onnxruntime as ort import numpy as np import json # 1. Load ONNX model and normalization statistics session = ort.InferenceSession("downloads/models/vehicle_speed_tcn.onnx") with open("downloads/models/normalize_stats.json") as f: stats = json.load(f) means = np.array(stats["mean"]).reshape(1, 8, 1) stds = np.array(stats["std"]).reshape(1, 8, 1) # 2. Window of raw 8-channel IMU data across 40 steps @ 10 Hz # Shape: [Batch=1, Channels=8, TimeSteps=40] raw_imu = np.random.randn(1, 8, 40).astype(np.float32) # 3. Normalize input normalized_input = (raw_imu - means) / stds # 4. Run real-time edge inference (~11ms on mobile CPU) inputs = {session.get_inputs()[0].name: normalized_input.astype(np.float32)} output = session.run(None, inputs)[0][0] predicted_speed_mps = float(output[0]) predicted_speed_kmh = predicted_speed_mps * 3.6 variance = float(np.exp(output[1])) print(f"Predicted Speed: {predicted_speed_kmh:.2f} km/h ({predicted_speed_mps:.2f} m/s)") print(f"Uncertainty (R_k): {variance:.4f}")
